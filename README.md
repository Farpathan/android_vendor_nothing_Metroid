# android_vendor_nothing_Metroid

Proprietary vendor blobs for the Nothing Phone (3) (Metroid), used by the PixelOS (Android 17) device tree at
[Farpathan/android_device_nothing_Metroid-pixelos](https://github.com/Farpathan/android_device_nothing_Metroid-pixelos).

Generated by `extract-files.py` / `setup-makefiles.py` from the device tree. Do not edit by hand.

Files over 50 MB are stored with Git LFS; run `git lfs pull` after cloning.
